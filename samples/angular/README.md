# Angular sample

A walkthrough for scanning an Angular application with SonarQube. No source files are committed here — the setup script scaffolds a fresh Angular project using the official CLI, runs tests with Karma/Jest coverage, and submits results to your local SonarQube instance.

This approach reflects real-world usage: your Angular project lives in its own repository; this sample shows you exactly what to add to it.

## What this demonstrates

- TypeScript and HTML template analysis
- Test coverage import from a Karma LCOV report (or Jest)
- Exclusion of generated files (`dist/`, `node_modules/`, `*.spec.ts` from source analysis)
- Angular-specific code smell detection (unused imports, template issues)

## Prerequisites

- [Node.js 22+](https://nodejs.org/) and npm
- [Angular CLI](https://angular.dev/tools/cli): `npm install -g @angular/cli`
- SonarQube running locally (`docker compose up -d` from the repo root)
- SonarScanner CLI: `npm install -g sonar-scanner` (or use `npx sonar-scanner@latest`)

## Step 1 — Scaffold a new Angular project

Run the setup script provided in this directory:

```bash
chmod +x setup.sh   # only needed once
bash setup.sh
```

This creates a `my-angular-app/` folder with a default Angular application generated by `ng new`. The script also copies the `sonar-project.properties` template into the project.

Alternatively, do it manually:

```bash
ng new my-angular-app --routing=false --style=css --skip-git
cd my-angular-app
```

## Step 2 — Add coverage reporting to karma.conf.js

Open `my-angular-app/karma.conf.js` and ensure `coverageReporter` is configured for `lcov`:

```js
coverageReporter: {
  dir: require('path').join(__dirname, './coverage'),
  subdir: '.',
  reporters: [
    { type: 'lcov' },
    { type: 'text-summary' }
  ]
}
```

In `angular.json`, under `test > options`, set:

```json
"codeCoverage": true
```

## Step 3 — Run tests with coverage

```bash
cd my-angular-app
ng test --watch=false --browsers=ChromeHeadless
```

Coverage is written to `coverage/lcov.info`.

## Step 4 — Create the project in SonarQube

1. Open <http://localhost:9000>
2. Log in (`admin` / your password)
3. Click **Create project** → **Manually**
4. Set **Project key**: `sonar-samples-angular`
5. Set **Display name**: `sonar-samples / angular`
6. Click **Set up** → **Locally**
7. Generate a token and copy it

## Step 5 — Copy sonar-project.properties

Copy `sonar-project.properties` from this directory into `my-angular-app/`:

```bash
cp ../sonar-project.properties my-angular-app/
```

Or if you ran `setup.sh`, it is already there.

## Step 6 — Run the scanner

From inside `my-angular-app/`:

```bash
sonar-scanner -Dsonar.token=<your-token>
```

## View results

Open <http://localhost:9000/dashboard?id=sonar-samples-angular>.

## What to look for in the results

| Area | What SonarQube reports |
|---|---|
| **Issues** | Unused imports, `any` type usage, template binding issues |
| **Coverage** | Line and branch coverage from Karma |
| **Duplications** | Detected across TypeScript and HTML files |
| **Security Hotspots** | Angular-specific patterns flagged for review |

## Adapting for an existing Angular project

Add `sonar-project.properties` to your project root and adjust:

- `sonar.sources` — your source folder (usually `src`)
- `sonar.tests` — leave blank or set to `src` (Sonar handles `.spec.ts` detection)
- `sonar.typescript.lcov.reportPaths` — path to your coverage output
- `sonar.exclusions` — expand as needed (e.g. `e2e/**`, `dist/**`)

## sonar-project.properties

```properties
sonar.projectKey=sonar-samples-angular
sonar.projectName=sonar-samples / angular
sonar.sources=src
sonar.exclusions=node_modules/**,dist/**,**/*.spec.ts,coverage/**
sonar.typescript.lcov.reportPaths=coverage/lcov.info
sonar.host.url=http://localhost:9000
```

The `sonar.token` is not stored here — pass it on the command line or via `SONAR_TOKEN`.
